# Item 24: initial capitalization in `comments`

Approved rule: capitalize the first character only when a nonblank `comments` value begins with a lowercase Russian letter.

Examples:

- `выкрест` → `Выкрест`
- `пришла за мужем` → `Пришла за мужем`

Digit-led and otherwise non-letter-led strings are outside the rule and remain unchanged, including precise ages such as `2 недели` and addresses such as `5-я Кирпичная`.

The change is staged from canonical v4. Canonical data remains unchanged pending a future release decision.
